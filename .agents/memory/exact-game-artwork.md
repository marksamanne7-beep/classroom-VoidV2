---
name: Exact game artwork
description: Quality and verification rules for matching web images to obscure browser-game catalog entries.
---

Prefer a game provider's own poster when it is available and usable. A web-search result must not replace it solely because the result title contains the catalog name.

**Why:** Obscure and abbreviated game names frequently return convincing but incorrect results, including unrelated sequels, memes, stock graphics, physical board games, and pages whose thumbnail does not match their title.

**How to apply:** Extract the canonical title from the exact game page when possible, search with both canonical and catalog titles, reject ambiguous matches, visually inspect candidates, and store approved posters locally. Use an exact-title fallback card when no trustworthy image is available.
