---
name: Background defaults
description: The intended first-run appearance and fallback behavior for Void V2 backgrounds.
---

The default appearance uses the bundled black-and-white neon-wave video behind Flowing Stars at minimum intensity, with mouse interaction enabled.

**Why:** This is the requested first-run experience, while user-selected local images, videos, and effect settings should remain respected.

**How to apply:** Use the bundled video and its poster as the fallback when no custom background is active. Preserve custom selections and allow users to disable the default video.
